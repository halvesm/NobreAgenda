# Sistema de Agendamento de Espaços Educacionais

Este projeto consiste em um **sistema web para controle e gerenciamento de agendamento de espaços educacionais**, como salas de aula, laboratórios, auditórios e demais ambientes acadêmicos.

O sistema tem como objetivo **organizar reservas**, evitar conflitos de horários e facilitar o uso compartilhado dos espaços de forma eficiente e transparente.

---

## 🧠 Tecnologias Utilizadas

- Node.js  
- Gemini API (Google AI Studio)  
- Ambiente de desenvolvimento local com suporte a variáveis de ambiente
